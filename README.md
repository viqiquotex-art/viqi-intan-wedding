# Viqi & Intan — Wedding Invitation

Aesthetic, mobile-first digital wedding invitation for **Viqi Septiawantoro & Intan Maharani**.

## Features
- Earthy romantic / Gen Z-inspired design
- Responsive mobile-first layout
- Guest personalization through `?to=intan`
- Cover opening interaction and scroll reveal animations
- Soft ambient melody generated by Web Audio API (starts after a user gesture)
- Gallery with replaceable demo imagery
- Countdown/event placeholders
- Demo RSVP and wishes stored only in the visitor's own browser (`localStorage`)

## Publish
This repository includes a GitHub Actions workflow at `.github/workflows/deploy.yml`. In the repository, open **Settings → Pages** and select **GitHub Actions** as the build/deployment source. The workflow deploys the repository root whenever changes are pushed to `main`.

After deployment, the website should be available at `https://viqiquotex-art.github.io/viqi-intan-wedding/`.
